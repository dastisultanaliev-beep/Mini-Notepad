# Mini Notepad 📝

A simple desktop notepad application built with Python and CustomTkinter.

## Features

- Write and edit text.
- Count characters automatically.
- Clear all text with one click.
- Save notes to a text file.
- Dark mode interface.
- Simple and user-friendly design.

## Requirements

- Python 3.10 or newer
- CustomTkinter

## Installation

Install the required library:

```bash
pip install customtkinter
```

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the application:

```bash
python main.py
```

## How to Use

1. Type your text into the text area.
2. Check the character counter below the text area.
3. Click **Clear** to erase the text.
4. Click **Save** to save your note to `note.txt`.
